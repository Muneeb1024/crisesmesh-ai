## Decisions Made

1. **Template**: Used `blank-typescript` over `tabs` template for cleaner base
2. **Styling**: Used StyleSheet.create instead of NativeWind for screen-level styles (more reliable for complex layouts)
3. **State**: Used Zustand over Redux for simplicity in MVP
4. **Navigation**: Used native stack for performance, not drawer/tabs initially
5. **Theme**: Implemented dual-palette in constants rather than context provider
6. **Government sidebar**: Implemented as inline component, not separate drawer navigator
