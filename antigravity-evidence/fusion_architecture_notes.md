# System Architecture Knowledge Base

## Core Engine: 8-Signal Fusion Architecture
We have decided to build an advanced 8-Signal Fusion Engine to power our multi-agent coordination system. This architecture specifically addresses the "Multi-Signal Fusion" and "Handling Misinformation" requirements of the hackathon challenge.

To balance technical feasibility with real-world smart city requirements, the signals are split into 3 Real APIs and 5 Mocked Telemetry streams.

### 🟢 Real-Time / Live Signals (3)
1. **Citizen Portal (Direct App Data)**: Real-time text, voice, and image reports directly from the React Native citizen app.
2. **Weather & Environmental Data**: Live integration with the Open-Meteo API to fetch real-time precipitation and temperature data for the target area (e.g., Islamabad).
3. **Social Media Firehose (AI-Simulated)**: A dynamically generated stream using an LLM to simulate chaotic public posts (like X/Twitter) reacting to live events.

### 🔵 Mock / Simulated Telemetry (5)
These signals are generated by backend Python scripts to simulate smart-city hardware and private institutional data:
4. **Traffic Congestion**: Simulated road speeds and bottlenecks (e.g., Kashmir Highway at 8 km/h).
5. **IoT City Sensors**: Simulated water-level meters in nullahs and temperature readings on power grids.
6. **Emergency Call Center (1122)**: Simulated metadata tracking sudden spikes in emergency call volumes per sector.
7. **Hospital ER Capacity**: Simulated status of available beds and trauma centers.
8. **Automated Drone/CCTV Feed**: Simulated computer vision output providing text summaries of road blockages or crowds.

*Note: These details will be used at the end of the project to construct the final README and architectural traces for the judges.*
